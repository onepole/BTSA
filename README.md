# BTSA

BTSA is the C++ implementation of the balanced tabu search algorithm (BTSA) used in our manuscript:

> A job shop scheduling model based on fuzzy induction strategy and balanced search mechanism

This repository currently provides the executable of BTSA. The source code will be publicly released in this repository upon acceptance of the paper.

## Requirements

- Windows

## Usage

1. Open the Windows command prompt (`cmd`).
2. Go to the folder containing `BTSA.exe`:

Run the program with an instance file:

cmd
BTSA.exe C:\path\to\instances\la29.txt
